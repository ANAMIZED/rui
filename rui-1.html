About this console

Single-file port of the RUI reference implementation. The model backend is a deterministic in-page simulator (tiered quality, context windows, latency) — but the budgets, breakers, kill switches, metering, frozen evaluation, staged promotion, rollback and audit trail are the real mechanisms, and generated code really runs against its tests in your browser. No network calls; state lives in memory.
