# Security Policy

## Reporting a Vulnerability

Please open a private security advisory on GitHub or contact the maintainers directly.

Do not disclose security issues publicly until they have been addressed.

## Scope

RUI is a research / prototype recursive agentic OS. Production deployments should:

- Keep outer meta-loops under human / high-assurance gates
- Enforce hard token and dollar budgets
- Treat constitutional invariants as non-negotiable
- Run under least-privilege NHI and policy
